# Gouri Shankar Ganuga Nune (Ghani) - Official Website

A high-performance, modern, and SEO-optimized e-commerce landing website for **Gouri Shankar Ganuga Nune**, traditional wooden ghani (Mara Chekku) cold pressed oils located in Chikkadpalli, Hyderabad.

Inspired by premium grocery website UI best practices (Subframe grocery design benchmarks).

---

## 🌟 Key Features

1. **Modern Grocery UI & Design System**:
   - Custom palette: Forest Green (`#14532d`), Honey Amber (`#f59e0b`), and Warm Cream (`#fbfaf6`).
   - Clean Google Fonts typography (`Outfit` and `Plus Jakarta Sans`).
   - Micro-interactions, hover zooms, and smooth transitions.
2. **Interactive Catalog & E-Commerce**:
   - 11 Authentic cold pressed oils & by-products with genuine high-resolution imagery.
   - Dynamic size switcher (500 ml, 1 L, 5 L) with live price and discount recalculation.

   - Itemized cart with quantity modifiers and persistent `localStorage`.
   - Free Hyderabad Delivery Progress Meter (Threshold: ₹999).
   - Order Type switcher: Home Delivery (Hyderabad) or Store Pickup (Chikkadpalli).

   - "Why Wood Ghani vs Refined Oils" comparison table.

   - Store directions, timings (9:00 AM – 9:00 PM), and Google Maps integration.

5. **Full SEO & Schema.org Optimization**:
   - Single semantic `<h1>` tag with structured `<h2>` and `<h3>` tags.
   - Complete `GroceryStore` & `LocalBusiness` JSON-LD structured data.

6. **Zero Dependencies & Fast Performance**:
   - 100% Vanilla HTML5, CSS3, and modern ES6 JavaScript.
   - No npm build step required — lightning fast load times.

## 🚀 How to Deploy to GitHub Pages for FREE (Step-by-Step)

### Option A: Using GitHub Desktop or Git Command Line

1. **Initialize Git** in this folder (if not already done):
   ```bash
   git init
   git add .
   git commit -m "Launch new Gouri Shankar Ganuga Nune website"
   ```

2. **Create a new Repository on GitHub**:
   - Go to [github.com/new](https://github.com/new).
   - Name your repository (e.g., `gouri-shankar-oils` or `<your-username>.github.io`).
   - Leave it **Public** (required for free GitHub Pages).
   - Click **Create repository**.

3. **Push your code to GitHub**:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```

4. **Enable GitHub Pages**:
   - On GitHub, click on **Settings** (gear icon) at the top of your repository.
   - In the left sidebar, click on **Pages**.
   - Under **Build and deployment** > **Branch**:
     - Select `main` (or `master`).
     - Folder: select `/ (root)`.
     - Click **Save**.
   - Within 60 seconds, GitHub will provide your free live URL:
     `https://<your-username>.github.io/<your-repo-name>/`

---

### Option B: Uploading Directly on GitHub Website (No Command Line Needed)

1. Go to [github.com](https://github.com) and create a new **Public** repository.
2. Click **Upload an existing file**.
3. Drag and drop all files and folders (`index.html`, `404.html`, `.nojekyll`, `css/`, `js/`, `assets/`) into the GitHub upload area.
4. Click **Commit changes**.
5. Go to **Settings** > **Pages** > Select `main` branch > `/ (root)` > Click **Save**.

Your website will be live worldwide for free!
